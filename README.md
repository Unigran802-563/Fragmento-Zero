# Fragmento Zero

## Carta
- Tema: Observatório com meteoros vivos
- Tipo: Fuga
- Modo: Horda — vista de cima

## Como jogar
Use as quatro direções do teclado para se movimentar.
Desvie dos meteoros vivos e sobreviva até a saída da cabine destrancar, após 60 segundos.
Alcance a saída para vencer.
